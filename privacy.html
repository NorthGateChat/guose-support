国色隐私说明

开发者：Xiaorui Huang · 生效日期：2026-09-28

1. App 中的数据

国色的核心色谱、阅读内容和图像内置于 App。浏览、阅读、检索、收藏和制作分享图无需注册。当前版本不向开发者服务器上传你的浏览记录、收藏、照片或个人资料，不包含广告或行为分析 SDK，也不进行跨 App 追踪。

收藏、浏览位置、偏好及分享构图设置保存在设备本地。App 不提供账号云同步。系统备份、恢复和迁移可能按你的系统设置处理本地数据，这不同于 App 主动上传到开发者服务器。

2. 照片、分享与外部链接

只有你选择保存分享图时，App 才请求向照片库添加图片的权限，不读取已有照片。拒绝后仍可使用浏览、阅读、检索、收藏与系统分享。当前主体验不请求相机、麦克风或定位权限。

你决定把分享图交给哪个 App 或服务；接收方按其隐私政策处理。App 不会替你自动发布。主动打开资料出处链接时，外部网站可能处理网络请求信息，其政策独立于本说明。

3. 主动邮件联系

只有你主动发邮件联系时，支持邮箱才会收到你的邮件地址、来信内容及自愿提供的附件；这些信息仅用于处理反馈与沟通。本网站没有反馈表单，点击邮箱链接不会自动发送邮件。邮件服务提供方按各自政策处理邮件。请不要发送密码、证件或与问题无关的敏感信息。

支持邮件由开发者本人处理，仅用于答疑和内容订正。仅在处理这些事项所需期间保留相关邮件和附件；问题处理完后，删除不再需要的信息。你可以向 xiaorui_huang@163.com 发邮件请求删除你提供的反馈信息。

4. 本静态网站

本页代码不设置 Cookie，不使用访问统计、广告、追踪脚本或第三方嵌入内容；字体和样式不依赖外部服务。这不等于托管服务没有访问记录。

本网站由 GitHub Pages 托管。GitHub 会为安全目的记录和保存访客 IP 地址，即使访客没有登录。参见 GitHub Pages 数据收集说明及 GitHub 隐私声明。App 的本机处理与网站托管是不同情境。

5. 管理数据与联系

你可以在 App 中取消收藏、调整或重置分享构图。卸载时的本地数据处理及备份副本由系统管理；已保存到照片或发送给其他服务的图片，需要在对应位置另行管理。

本说明反映当前版本；如数据处理方式变化，说明和商店披露也需相应更新。隐私或反馈信息问题，请联系 xiaorui_huang@163.com。

國色的核心色譜、閱讀內容和圖像內建於 App。瀏覽、閱讀、搜尋、收藏及製作分享圖片無需註冊。目前版本不會向開發者伺服器上傳你的瀏覽記錄、收藏、照片或個人資料，不包含廣告或行為分析 SDK，也不進行跨 App 追蹤。

本頁程式碼不設定 Cookie，不使用流量統計、廣告、追蹤腳本或第三方嵌入內容；字型和樣式不依賴外部服務。這不等於託管服務沒有存取記錄。

本網站由 GitHub Pages 託管。GitHub 會基於安全目的記錄並儲存訪客 IP 位址，即使訪客未登入。請參閱 GitHub Pages 資料收集說明及 GitHub 隱私聲明。App 的本機處理與網站託管是不同情境。

5. 管理資料與聯絡

Guose privacy notice

Developer: Xiaorui Huang · Effective date: 2026-09-28

1. Data in the app

Core colors, reading material and artwork are included in Guose. Browsing, reading, search, favorites and share-image creation need no account. The current version does not upload your browsing history, favorites, photos or personal details to developer servers. It has no advertising or behavioral analytics SDKs and does not track you across apps.

Favorites, browsing position, preferences and share composition settings are stored on your device. Guose has no account-based cloud sync. System backups, restoration and migration may handle local data according to your device settings; this is separate from an app uploading data to developer servers.

2. Photos, sharing and external links

Guose requests permission to add an image to Photos only when you choose to save. It does not read existing photos. Declining does not affect browsing, reading, search, favorites or system sharing. The current main experience does not request camera, microphone or location access.

You choose the receiving app or service in the system share sheet; its privacy policy applies. Guose does not publish images for you automatically. If you open a reference link, the external website may process network-request information under its own policy.

3. Email you choose to send

If you email support, the support mailbox receives your email address, message and any attachments you choose to include. This information is used only to handle your feedback and communicate with you. This website has no feedback form, and clicking an email link does not send a message automatically. Email providers handle mail under their own policies. Please do not send passwords, identity documents or unrelated sensitive information.

The developer personally handles support email, only to answer questions and make content corrections. Relevant messages and attachments are retained only for as long as needed for those purposes; information no longer needed is deleted after the issue is resolved. You can email xiaorui_huang@163.com to request deletion of feedback information you provided.

4. This static website

This page’s code does not set cookies or use analytics, advertising, tracking scripts or third-party embeds. Fonts and styling do not depend on external services. This does not mean the hosting provider has no access logs.

This website is hosted on GitHub Pages. GitHub logs and stores visitors’ IP addresses for security, including visits without signing in. See GitHub Pages data collection and the GitHub Privacy Statement. Website hosting is separate from the app’s on-device processing.

5. Managing data and getting in touch

You can remove favorites and adjust or reset share compositions in the app. The operating system manages local data on uninstall and copies in system backups. Images already saved to Photos or sent to another service must be managed in those destinations separately.

This notice describes the current version. Changes to data handling also require corresponding updates to this notice and store disclosures. For questions about privacy or information you sent in feedback, contact xiaorui_huang@163.com.
